Objetivo
Nesta Sprint, sua equipe deve implementar uma solução baseada em uma das disciplinas a seguir: JAVA ADVANCED OU ADVANCED BUSINESS
DEVELOPMENT WITH .NET

A solução deve ser implementada junto com um banco de dados na nuvem
Escolha uma das opções abaixo:
Opção 1: ACR + ACI
Utilize Azure Container Registry (ACR) para armazenar sua imagem Docker e Azure Container Instance (ACI) para executar o container. Ambos devem ser
utilizados nessa opção. Solução containerizada completa: App e Banco
Opção 2: Serviço de Aplicativo (App Service)
Publique sua aplicação em um App Service na Azure, com o banco de dados também na nuvem - Aqui nada pode ser Containerizado
